# Assets

Record images downloaded for the tree. Every file is listed with what it shows, where it came
from, and who holds the rights, so the attribution travels with the image.

## West Virginia Archives & History

- `1938-monongalia-marriage-clemmer-dunham.jpg` — Monongalia County marriage register,
  pp. 432–433: license application, license and minister's return for William Bryan Clemmer and
  Margaret Belle Dunham (the right-hand page), 29 Sep – 14 Oct 1938. West Virginia Vital Research
  Records, record 11349379 (film 4231506, frame 00248).
  <https://archive.wvculture.org/vrr/va_mcdetail.aspx?Id=11349379>
